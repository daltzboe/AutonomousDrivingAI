# Experiment Protocol

This protocol operationalizes the research methods and metrics in the midterm presentation. It is a plan, not a report of completed experiments.

## Research question

Can we effectively train and evaluate autonomous driving AI in a simulated environment without exposing real vehicles or people to safety risks?

## Comparison

- **Reference controller:** CARLA BasicAgent, a rule-based route-following agent with PID control and obstacle response.
- **Learning controller:** a compact CNN trained by imitation learning to predict steering from a front RGB camera image. Expert steering labels are generated by BasicAgent in CARLA.
- **Primary comparison:** run both controllers through the same set of CARLA start/destination pairs.

## Experimental controls

Keep these identical between controllers:

- CARLA server version and map
- vehicle blueprint
- camera position, resolution, and field of view
- simulation fixed timestep and target speed
- start/destination pairs and route protocol
- weather and traffic configuration (initial study uses the same CARLA world configuration; document any changes)
- episode step limit and collision sensor

Record any deviation from these controls in the run metadata.

## Data and split

Collect camera images with steering, throttle, brake, speed, position, and yaw from simulation. Use whole episodes for the train/validation split so neighboring frames from the same drive do not appear in both subsets. Do not use the held-out validation episodes to select training labels or tune the model.

The current collector uses a small number of routes for a course project. This is an exploratory comparison; results should not be generalized to all roads or weather.

## Metrics

1. **Steering MAE:** mean absolute error between predicted and BasicAgent-recorded steering on held-out episodes. Units: normalized steering command (range [-1, 1]).
2. **Collision rate:** episodes with one or more collision events / total valid evaluation episodes × 100%.
3. **Lane deviation:** mean planar distance in meters between the vehicle location and its projected driving-lane waypoint center.
4. **Route completion:** completed assigned routes / total valid evaluation episodes × 100%.

Report raw episode outcomes and aggregate values. Also report failed vehicle spawns and simulator errors separately; do not quietly exclude them.

## Expected interpretation

Lower steering MAE and lane deviation are better. Lower collision rate is better. Higher route completion is better. A low steering MAE alone does not establish safe or successful driving.

## Limitations

- The learned controller predicts steering only; throttle is held at a documented fixed value during evaluation.
- The expert labels reflect BasicAgent behavior, so imitation learning learns that controller's driving style and limitations.
- CARLA results are simulation results, not evidence of real-road readiness.
- Five episodes are an initial smoke/benchmark sample, not a statistically strong evaluation. Increase routes and repetitions before drawing conclusions.
